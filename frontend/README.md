# CloudTrace Incident Hub - Front-End Workspace

## Overview
Responsive real-time incident management console engineered with React 18, TypeScript, and Tailwind CSS.

## Three Interconnected Core Views
1. **Landing Page (`/`):** Value proposition, telemetry metrics, and feature breakdown.
2. **Incident Dashboard (`/dashboard`):** Real-time incident feed, severity filter (P1-P3), and search.
3. **War Room Canvas (`/incidents/:id`):** Telemetry detail, status toggles (Acknowledge/Resolve), and live timeline log.

## Quickstart Guide
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build
```
